macOS 13+ · Apple Silicon Native

iPhone & Mac Battery,
always in view.

A lightweight, translucent floating macOS desktop widget and deep battery analytics dashboard for MacBooks, iPhones, and iPads.

Download .DMG GitHub Repository ☕ Support on Ko-fi
⚡

Live Dual-Device Tracking

Real-time capacity, wattage, amperage, voltage, and accurate cycle counts for your Mac and connected iPhones or iPads simultaneously.

🌡️

Hardware NTC Thermistor

Direct live sensor temperatures with dynamic thermal gradient indicators, rate trends, and high-heat safety alerts.

📈

Degradation Trajectories

Comprehensive historical analytics and multi-month battery capacity degradation curves with CSV export & coconutBattery archive import.

🔌

Dual Connection Engine

Native high-speed USB `usbmuxd` lockdown communication with seamless Wi-Fi sync fallback when disconnected from cable.

💻

Lid & Session Tracker

Monitors MacBook clamshell open/close cycles, active work sessions, and screen-on durations automatically.

💎

Glassmorphic Floating UI

Always-on-top translucent dark glass design that docks anywhere on your screen and blends seamlessly with macOS.

Quick Installation

Download the pre-compiled DMG or build from source in seconds:

git clone https://github.com/LondonVista/iPhoneBatteryWidget.git
cd iPhoneBatteryWidget
./build.sh --release
